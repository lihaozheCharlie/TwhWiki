# 诚实反馈者

## 关系功能

这类关系不负责鼓励一切，也不把尖锐当作诚实。他们能指出作品中真正清楚和真正含糊的部分，同时把反馈留在作品上，不顺手给人的能力和未来下总判断。

[[02 被取消的周末]]里那句“你是真的想做，还是只是不习惯让别人失望”，提供了另一种诚实：不是替人决定要不要离开，而是指出行动与真实愿望之间的缝隙。

[[04 把作品发给五个人]]中两类反馈同样重要——一条说明哪里发生了真实帮助，一条说明哪里无法理解。好的反馈关系让正面与负面信息都能进入，而不需要先把其中一种解释成身份裁决。

## 边界

- 反馈服务于作品迭代，不替代自己的方向判断。
- 不把一次意见升级成身份结论，也不要求所有反馈彼此一致。
- 关系中的支持不只在“给建议”；有时只是帮助区分现在真正害怕的是什么。
