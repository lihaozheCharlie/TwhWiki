# 近况回信阅读界面

本说明记录回信页与生活记录时间筛选的局部扩展，依据已实现组件；沿用现有 `PRODUCT.md`、`DESIGN.md`，不替换全局设计系统。面向桌面端，不新增移动端布局。

## 页面结构

- 页面只有一个主标题区：近况回信、简短说明与回信总数；其下是一条横向筛选区：阅读方式、年份或主题选择、排序提示，空间不足时允许控件换行。
- 主体为左索引与右正文。索引宽（260px），可收起；仅显示日期与去除日期前缀的标题，不重复摘要、主题或来历。
- 回信始终按写信时间从新到旧排列。筛选后优先保留范围内的 URL 指定回信，否则展示第一封。
- 正文顶部的紧凑信息行包含写信日期、材料日期范围、主题、版本选择和重读入口。主题先显示两个，其余放入“+数量”展开区域。

## 阅读与编辑

- 原始回信与其他知识页面复用同一个 `EditableDocument`，不再设置回信专属正文宽度、字号、内边距或布局覆盖；右侧容器不额外叠加编辑器内边距。
- 继续使用既有纸面、墨色、边线和标题字体；选中索引以淡底和左侧强调线识别，不引入全局新色板。
- 原始回信加载完整正文，保留双击或 Enter／F2 编辑、失焦保存、Ctrl／Cmd+S 保存与 Escape 退出编辑；生成版本只提供完整 Markdown 阅读，不作为原始文件的编辑副本。
- 工具栏、页面属性、正文与目录沿用公共编辑器顺序；正文有多个标题时显示目录，进入编辑后使用完整宽度。
- 生成版本使用共享 `ReadOnlyDocument`，与编辑器共用 `DocumentFrame` 和 Markdown 渲染、正文样式及目录规则，不接入文件保存逻辑，避免历史快照覆盖原始回信。回信页面只提供来历和版本操作，不维护另一套文档布局。

## 版本与重读

- 原始回信始终保留；生成版本仅纳入该回信已完成且有正文的运行结果，默认展示最新版本。没有生成版本时显示原始回信，并隐藏版本选择器。
- `letter` 与 `version` URL 参数保留指定回信及原始／历史版本深链；切换回信或筛选时清除旧版本选择。
- 生成版本显示视角名称、生成时间与“查看生成对话”，保留生成来历。
- “用其他视角重读”默认关闭；点击切换，选择视角后关闭并打开协作入口。Escape、外部点击或焦点离开也会关闭；Escape 将焦点送回触发按钮。
- 弹层根据可用视口高度选择上方或下方展开，限制高度并允许内部滚动；窗口变化与滚动时重新测量。
- 重读请求要求只依据已有材料、不虚构事实、不模仿口头禅，并在末尾列出依据；输出保存为版本，不改写文件。

## 共用筛选边界

- `TimelineFilter` 是受控展示组件：接收当前值、选项标签与数量、总数、回调，以及可选前置内容和提示。
- 空值表示全部；当前值不在选项中时仍展示该值及零数量，避免把失效筛选误显示为“全部”。
- 回信页提供年份或主题，生活记录页提供月份；共用结构、间距和焦点样式。组件不解析日期、不请求数据、不管理 URL，筛选语义、排序与状态由调用页负责。
- 回信的年份、主题和阅读方式保存在页内状态；回信及版本选择进入 URL。生活记录月份继续使用既有 URL 状态，修改月份时清除文件选择和分页限制。

## 异常与验证

- 保留加载、空范围、读取失败反馈；版本历史失败时提示并继续展示原始回信，重读视角失败也有提示。
- 自动化测试覆盖共用筛选的数量、月份标签、失效值、空数据与回调，以及回信索引、主题溢出、版本默认与深链、正文顺序、空态及历史读取失败回退。
- 编辑器统一修复后，类型检查、171 项测试与生产构建通过；回归测试校验原始回信与其他知识页生成完全相同的编辑器结构，历史版本共用布局但不可编辑。
- 使用匿名测试库在 1280、1440、1600px 桌面宽度检查阅读与编辑区域，无横向溢出；验证双击／F2 进入编辑、快捷键保存后刷新、失焦保存及收起索引后的完整编辑宽度。
- 本轮通过匿名演示库进行桌面浏览器检查；复核记录的局部行动文字对比度为纸面（5.33:1）和选中底色（4.89:1）。
- 未进行真实 AI 重读生成；界面入口与既有版本展示的验证不能等同于生成链路实测。
