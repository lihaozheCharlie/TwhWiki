# 非日记来源摄取

用于当前任务需要摄取的读书笔记、历史笔记、文章或其他非日记来源材料。

1. 完整读取来源并识别其主要证据对象。
2. 填写 `knowledge-engine/skills/build/wiki-build/impact-matrix.md` 每一行，不要使用为特定来源缩短的子集。
3. 更新合适的来源索引。
4. 只有来源改变判断、边界、机制，或提供代表性证据时，才更新综合页。
5. 外部学习必须说明它解释了哪个个人问题、可以防止哪个错误，或更新了哪个思维模型。
6. 保留准确来源链接并应用质量门。

被读过不代表来源具有高价值；不要把有用的模型变化只埋在来源索引中。
