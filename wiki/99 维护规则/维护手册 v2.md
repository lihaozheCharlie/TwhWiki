# 维护手册 v2

## 日常查询

从 [[wiki/index|Wiki 首页]] 进入，先读相关综合页，必要时才回到 `原始知识库/` 核对。查询默认只读；发现缺失时报告缺失，不自动补写。

## 新材料摄取

1. 明确本次来源范围和写入授权。
2. 读取原始材料，不先根据标题猜结论。
3. 填写完整影响矩阵，每层标为 `update`、`link-only`、`no-op` 或 `defer`。
4. 把更新交给唯一领域负责人，保留其他既有改动。
5. 更新必要的来源索引、公共导航与 [[wiki/log|构建日志]]。
6. 运行质量门并人工复核重要解释。

## 证据规则

- 事实、用户解释和模型推断要能区分。
- 原句值得保留时精确引用，并链接来源。
- 人物视角只提供解释，不构成事实来源。
- 没有证据的模板章节应省略，而不是填入占位句。

## 完成标准

```bash
python3 tools/update_obsidian_tags.py
python3 tools/update_obsidian_tags.py
python3 tools/validate_wiki_links.py
python3 tools/validate_skill_system.py
```

第二次标签更新必须为 `updated=0`，链接必须 `missing=0 ambiguous=0`。公开分享前还要运行 `python3 tools/privacy_scan.py`。
