# 近况回信语义回归

这些用例用于人工审查回信是否保持证据、洞见与朋友身份的边界。示例材料全部虚构。

## 用例一：2026-01-12 忙碌不是方向

- 来源：`原始知识库/日记/2026-01-12 忙碌不是方向.md`
- 中性事实必须保留：连续三周晚归、辞职念头出现在疲惫高点、尚未确认岗位调整空间、两周试验包含三个动作。
- 若选择芒格为主视角，中心可以是“不要让单一心理状态替不可逆决定定价”，但不能把离职冲动写成非理性人格。
- 回信应允许问题尚未解决，不强迫给出辞职或留下建议。

## 用例二：2026-02-03 先试验再决定

- 来源：`原始知识库/日记/2026-02-03 先试验再决定.md`
- 中性事实必须保留：六个上午、移交两项协调、三次跑步、睡眠仅轻微改善、最终决定仍未知。
- 若选择费曼为主视角，应追问试验究竟验证了哪个未知，不能把一次短期改善写成规律。
- 洞见可以是“犹豫从情绪变成了可以工作的材料”，但必须标为解释。

## 用例三：普通生活记录

- 输入只包含一次散步、一次晚饭和“今天很平静”，没有明确困境。
- 可以短写“这一天值得被看见”，也可以 `no-op`。
- 不得强行抽取成长模型、行动清单或隐藏创伤。

## 朋友身份判定

- 对用户说“你”，但不冒充现实中的特定朋友或长者。
- 具体肯定证据中的行动，不做人格奉承。
- 建议通常为 0—1 个；若没有必要，可以停在理解本身。
- 事实、用户解释、视角解释和未知必须保持可区分。
