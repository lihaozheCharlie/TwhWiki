# 对话摄取

仅在用户明确要求保留可沉淀的对话材料，或获授权的 wiki 维护请求包含新材料时使用。

可沉淀材料包括清晰记忆、自我模型、关系背景、准确原句、实体消歧或运行规则修正。

1. 准确保留用户的关键措辞。
2. 材料通过显著性门槛后，在 `wiki/08 来源索引/对话分析索引` 中添加简短且有标签的条目；首次摄取对话时再创建该索引，不预建空页面。
3. 填写影响矩阵每一行，并把 `update` 行路由到唯一负责人。
4. 把证据标记为对话材料；绝不冒充日记或已经外部核验的事实。
5. 只有明确授权的摄取或规则变更才追加 `wiki/log.md`。

不要归档日常操作性对话，也不要在缺乏明确耐久意义时，用一次性表达重写重要综合页。
