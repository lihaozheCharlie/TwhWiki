# 共享推理视角跨领域回归

以下规格用于人工验证人物视角没有污染证据或越过领域边界。示例材料全部虚构。

## 同一来源，不同主视角

来源：`原始知识库/日记/2026-01-12 忙碌不是方向.md`

- 芒格为主：可以从激励、机会成本和不可逆决定进入，检查“救火证明价值”是否形成错误反馈。
- 费曼为主：可以从可验证问题进入，追问两周试验究竟能排除哪些假设。
- 雅尼为主：可以注意“忙碌”和“方向”之间的生活感断裂，但不能把它写成来源已经陈述的情绪事实。

三种解释可以不同，连续三周晚归、辞职念头、岗位调整空间未知和三个试验动作必须完全一致。

## 同一主视角，不同输出层

仍以上述来源为样本，费曼为主：

- 事件页：围绕未知、选项、试验和决定标准组织。
- 思维模型页：抽象出“小试验增加信息”的机制与失效边界。
- 近况回信：用自然语言回应“还没有答案并不等于没有进展”。
- 查询回答：直接回答用户问题，不写入任何页面。

同一视角不能把四个输出层写成同一种文章结构。

## 中性层不受污染

无论选择哪一主视角，下列字段保持一致：日期、原句、人物、完成次数、选项、事件顺序和仍未知的最终结果。来源索引和 YAML 元数据不使用人物视角改写。

## 辅助越权

- 芒格主视角、雅尼辅助时，辅助只能检查是否把生活感和身体完全工具化，不能接管中心并改写成情感散文。
- 雅尼主视角、费曼辅助时，辅助只能校验某个证据跳跃，不能把整封回信改造成实验报告。
- 如果辅助内容改变主要结论或结尾，应重新选择主视角，而不是继续叠加。

## 新人物动态发现

在 `references/figures/` 临时加入一个符合协议的新文件后：

1. `list_lenses.py --check` 应通过；
2. `list_lenses.py --json` 应自动包含它；
3. 下游 Skill 不应修改任何名单才能发现它；
4. 删除临时文件后结果恢复。
