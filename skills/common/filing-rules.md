# 个人 Wiki 归档规则

## 首要规则

按长期模型发生变化的对象归档，而不是按来源格式归档。

| 信号 | 主要归档位置 |
|---|---|
| 个人长期命题或自我模型 | `wiki/01 个人主线/` |
| 阶段级变化 | `wiki/02 人生阶段/` |
| 重大事件或决策 | `wiki/03 关键事件与决策/` |
| 反复循环 | `wiki/04 反复循环/` |
| 人物在用户生活中的功能 | `wiki/05 人物关系图谱/`，必要时加实体页 |
| 家庭、职业、身体、资产、注意力、表达系统 | `wiki/06 现实系统/` |
| 作为证据节点的人物、城市、组织和项目 | `wiki/07 人物与城市/` |
| 来源导航和生成索引 | `wiki/08 来源索引/` |
| 可复用思维模型 | `wiki/09 思维模型/` |
| 用户选中或能唤回判断与动作的耐久原句 | `wiki/13 金句集锦/` |
| 跨年份时间线 | `wiki/02 人生阶段/人生阶段总览.md` 和相关人生阶段页 |
| 近期动态状态 | `wiki/11 状态追踪/` |
| 对最新日记的朋友式洞见回信 | `wiki/12 近况对话/` |
| 运行协议 | `wiki/99 维护规则/` 和 `skills/` |

## 原始来源

`原始知识库/` 是证据层，不是综合层。保留原始正文。允许的模型修改仅限前置元数据/标签和轻量 wiki 连接：

- `## 状态追踪`
- `## 相关日记`
- `## 关联`

## 显著性门槛

只有信号未来可能有用时，才创建或丰富页面：

- 人物、城市、组织或项目反复出现，或改变了既有解释；
- 用户原句凝结了耐久模型；
- 来源改变了既有页面的核心判断；
- 状态追踪项出现优化、劣化或新的可观察变化。

不确定时，先从来源笔记建立链接，暂缓新建页面。

## 回链规则

wiki 页面提及既有实体页或系统页时，在有用的情况下建立双向路径：

- 来源笔记通过 `## 关联` 链接到 wiki 页面；
- wiki 页面在 `source:` 或 `## 关键证据` 下列出来源；
- 新来源具有代表性时，索引页应能发现它。

重要来源如果只能从 `日记索引` 到达，说明链接不足。

## 引用规则

使用 Obsidian 链接作为引用。优先在 `source:`、`## 关键证据` 或局部证据条目中放置精确来源笔记链接。存在对话材料时才创建并引用 `wiki/08 来源索引/对话分析索引`；对话材料不能当作日记事实。
